# KaMoRaLe — The Islands Connect

KaMoRaLe is a Micronesian social community project: a place to connect across the islands, share stories, and build friendships.

## Website

https://islandmonkey691.github.io/KaMoRaLe/

## Source

This repository contains the KaMoRaLe website source. GitHub Pages publishes the site from the configured Pages source.

## Current development

The project is under active development. Features and availability may change as authentication, profiles, posts, friendships, messaging, notifications, media uploads, and moderation are completed.
